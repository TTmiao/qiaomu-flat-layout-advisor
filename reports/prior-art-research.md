# Prior-Art Research

## Scope

This first iteration studies the requested source catalog and the installed `qiaomu-meta-skill` authoring method. It does not claim a market-wide comparison.

## Sources

- `nevertoday/350-layout-compositions`: 350 categorized 2D layout references with JSON/CSV catalog fields and stable image paths.
- `qiaomu-meta-skill` v2.8.1: routing-first package structure, evidence boundaries, trigger evals, and explicit output contracts.

## Keep / Adapt / Reject / Invent

- Keep: stable case IDs, categories, subcategories, image paths, and dimensions.
- Adapt: case labels become retrieval signals, not proof of a design law.
- Reject: treating every catalog category as equally applicable to flat graphic design.
- Invent: an observation-to-law-to-action output chain, confidence labels, and a no-redesign default.

## Missing evidence

- No human review or user study has yet validated whether the inferred laws improve actual designs.
- No embedding or image-similarity benchmark is included in this first iteration.
- The upstream catalog's textual labels do not fully specify the visual rules; model judgment remains necessary.
