# Source Catalog

Primary source: `nevertoday/350-layout-compositions`.

- Upstream repository: `https://github.com/nevertoday/350-layout-compositions`
- Catalog JSON: `https://raw.githubusercontent.com/nevertoday/350-layout-compositions/main/v2/catalog.json`
- Catalog CSV: `https://raw.githubusercontent.com/nevertoday/350-layout-compositions/main/v2/catalog.csv`
- Stable image root: `https://raw.githubusercontent.com/nevertoday/350-layout-compositions/main/`

The catalog records `id`, `name`, `category`, `category_slug`, `subcategory`, `subcategory_slug`, high-resolution image path, thumbnail path, dimensions, and SHA-256. It does not encode a complete textual design theory. The Skill therefore treats catalog labels as retrieval signals and uses `references/layout-laws.md` plus visual inspection to form the diagnosis.

## Default category policy

Use these first for flat graphic design:

1. `01-composition-logic`
2. `02-visual-principles`
3. `03-editorial-advertising`
4. `04-type-grid-cjk`

Use `05-web-ui`, `06-film-frame`, `07-chinese-composition`, or `08-presentation` only when the requested artifact makes the transfer reasonable.
